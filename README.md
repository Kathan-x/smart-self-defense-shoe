# Smart Self-Defense Shoe

IoT-based smart self-defense shoe using NodeMCU ESP8266.

## Features
- Panic button
- Emergency/self-defense mechanism
- LCD/OLED display
- Relay control
- Embedded hardware integration

## Hardware
- NodeMCU ESP8266
- LCD/OLED
- Relay module
- Panic button
- High-voltage generator
- Battery
- Metal plate
